Step 3 · Pivot & merge asset groups

When a non-empty, non-zero block reference contains more than one asset group, those groups merge into a single asset group v2 — but the merge happens block by block. If A & B share block X and B & C share block Y, you get two independent merges (A+B for block X, B+C for block Y); they do not combine into A+B+C. Attributes are compared position-by-position: matching values stay, different values are joined with &. The asset group v2 is added to both the pivot table and the original property rows.

# Asset Group Automation

Automation for forming asset groups (V1, V2, V3, V4) from property / stock-condition survey data.

## Contents

- `Asset group formation.xlsx` — source workbook with example property data.
- `Asset Group Builder.html` — interactive UI for building asset groups from a spreadsheet.
- `asset-group-v1-formation/` — skill/automation for forming the Asset Group V1 column by concatenating selected attribute columns with a pipe delimiter.

## Status

Work in progress. V1 formation is the first step in a multi-step pipeline — V2, V3, V4 will be added later with different grouping logic.

# Asset Group Automation

Automation for forming asset groups (V1, V2, V3, V4) from property / stock-condition survey data.

## Contents

- `Asset group formation.xlsx` — source workbook with example property data.
- `Asset Group Builder.html` — client-facing launcher for the canonical browser app.
- `asset-group-v1-formation/assets/asset_group_builder.html` — canonical local browser app for V1 formation, V2 split-block merging, and V3 small-group consolidation.
- `asset-group-v1-formation/` — skill/automation bundle, including the app and local SheetJS dependency.

## Status

Work in progress. V1, V2, and V3 are implemented in the canonical browser app. V4 splitting of large asset groups and a final checks/audit step are still to be added.
